# Secure Spring Boot JWT Authentication API

A robust, secure, and production-ready backend authentication system built using modern enterprise Java standards. This project implements JSON Web Token (JWT) stateless authentication, password encryption, and role-based access control with Spring Security.

## 🚀 Tech Stack

* **Language:** Java 17
* **Framework:** Spring Boot 3.4.0
* **Security:** Spring Security & jjwt (0.12.6)
* **Database:** PostgreSQL (Dockerized)
* **ORM:** Spring Data JPA / Hibernate
* **Utilities:** Lombok, Maven

---

## ⚙️ Architecture & Features

* **Stateless JWT Authentication:** Secure token generation, validation, and claim extraction.
* **Password Encryption:** Strong hashing implementation via `BCryptPasswordEncoder`.
* **RESTful Endpoints:** Clean API structure for user registration and login workflows.
* **Containerized Database:** Isolated PostgreSQL database instance managed via Docker.
